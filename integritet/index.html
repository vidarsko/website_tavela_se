Integritet

Integritetspolicy

Den här webbplatsen använder inga kakor och samlar inte in några uppgifter som kan kopplas till dig.

Besöksstatistik

För att se hur många som besöker webbplatsen, och vilka sidor de läser, använder jag GoatCounter. GoatCounter sätter inga kakor, sparar ingenting på din enhet och lagrar inte din IP-adress. Det som sparas är vilken sida som visades, från vilken webbplats du kom, och ungefär vilket land, vilken webbläsare och vilken skärmstorlek du har. Ingenting av det kan användas för att känna igen dig, varken här eller på andra webbplatser.

Typsnitten ligger på webbplatsen själv. Utöver GoatCounter hämtas ingenting från andra servrar när du läser en sida.

Driften

Webbplatsen ligger hos GitHub Pages. Som alla webbservrar registrerar GitHub besökarens IP-adress när en sida hämtas, för säkerhet och drift. Det regleras av GitHubs integritetspolicy. Jag har ingen tillgång till de uppgifterna.

Om du mejlar mig

Om du skriver till mig använder jag din adress och det du skriver bara för att svara dig och för att ordna det vi kommer överens om. Jag delar det inte med någon.
